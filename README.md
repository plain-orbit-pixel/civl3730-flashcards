# CIVL 3730 midterm flashcards

90 core revision cards and 20 spelling cards, with separate meaning and spelling ratings. The site is responsive for phones, contains its mathematical fonts and renderer, and uses browser-local storage for ratings. Ratings are specific to each browser/device and do not sync through GitHub.

Open the published GitHub Pages link shown in the repository description, or download index.html and open it in a browser. Spelling inputs disable spellcheck and autocorrect. Reveal answers only after attempting recall.

## Scope

Topics I-VI plus Lab 1 and Lab 2, following the course midterm review. Topic VI scope is pages 1-67 and 86-89. Source labels refer to PDF pages of the original course notes and lab manuals. Questions and explanations are independently written revision summaries; numerical examples are hypothetical. Original lecture PDFs and laboratory records are not included.

Lab 1 uses the fall-cone liquid limit and 3 mm plastic-limit threads. Lab 2 uses British Standard light compaction. Diagrams are schematic. Cards complement full notes and written calculation practice.

## Hosting

Buildless static site. GitHub Pages publishes the main branch root. The study deck works without external web resources once downloaded; browser offline caching of the hosted address is not guaranteed.
